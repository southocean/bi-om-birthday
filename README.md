# Bị ốm birthday

Hưng's birthday, 12.10.2026: who owes whom (Swish / VietQR), the bills, and the photos.

- Everything the site shows is in `data.js` (people, bills, payments made, FX, gallery).
- Mark a payment as done by adding `{ from, to, kr, date }` to `PAYMENTS`.
- Local preview: `node tools/serve.js` → http://localhost:5179
